Student Marks Prediction

A beginner machine-learning project that trains a prediction model using multiple input features and student marks data.

About this project

Student Marks Prediction is a learning project for understanding the basic workflow of a machine-learning model. It uses multiple input features and a training loop to learn weights and bias before producing a prediction.

Key features

  • Multiple input features
  • Training data
  • Weights and bias updates
  • Prediction output

Development journey

This project is being used to learn machine-learning fundamentals by following the training calculations and understanding how model parameters are updated.
